## Что находится в этой папке

Здесь находится вторая лабораторная работа по Django.

Реализован вариант 4: сайт туристической фирмы со списком туров.

Функциональность:

- регистрация новых пользователей;
- вход и выход из аккаунта;
- просмотр списка туров;
- бронирование туров;
- редактирование и удаление своих бронирований;
- отзывы к турам с рейтингом от 1 до 10;
- подтверждение бронирований администратором;
- таблица проданных туров по странам;
- поиск, фильтр по стране и пагинация списка туров.

## Как запустить

1. Установить зависимости:

```bash
pip install -r requirements.txt
```

2. Перейти в папку проекта:

```bash
cd simple_django_web_project
```

3. Выполнить миграции:

```bash
python3 manage.py migrate
```

Если проверять проект на PostgreSQL, перед миграциями можно указать данные подключения:

```bash
export USE_POSTGRES=1
export POSTGRES_DB=tour_agency
export POSTGRES_USER=postgres
export POSTGRES_PASSWORD=postgres
export POSTGRES_HOST=localhost
export POSTGRES_PORT=5432
```

4. Запустить сервер:

```bash
python3 manage.py runserver
```

5. Открыть сайт:

```text
http://127.0.0.1:8000/
```

Админ-панель:

```text
http://127.0.0.1:8000/admin/
```

Через админ-панель можно добавлять туры. Подтверждать бронирования можно в админ-панели или на странице управления бронями, которая видна только администратору.
