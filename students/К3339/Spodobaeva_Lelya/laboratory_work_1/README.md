# Лабораторная работа 1. Сокеты

Сделала: Леля Сподобаева, К3339

5 заданий, всё на чистом socket, без http.server и подобных библиотек, то есть протокол собирала руками.

## Что где лежит

- task1_udp - обмен сообщениями по UDP
- task2_tcp - вычисление гипотенузы по катетам (вариант 1), сервер и клиент общаются через TCP в JSON
- task3_http - сервер сам собирает HTTP-ответ и отдаёт index.html
- task4_chat - чат на TCP с потоками, можно подключать несколько человек одновременно
- task5_web_server - веб-сервер с формой, сохраняет оценки в grades.json

## Запуск

В основном одинаково - сначала сервер, потом клиент, в разных терминалах:

```bash
python3 task1_udp/server.py
python3 task1_udp/client.py
```

Для task2_tcp так же, просто меняешь путь.

С task4_chat отдельный момент: сервер один, а клиентов нужно открыть минимум 2 (по-хорошему больше), иначе чат не с кем тестировать. Каждый клиент при заходе спрашивает имя, потом просто пишешь сообщения в терминал, все остальные их видят. Для выхода - /exit.

task3_http и task5_web_server - без клиента, просто открываешь браузер после запуска сервера:

```bash
python3 task3_http/server.py
```
-> http://127.0.0.1:5003

```bash
python3 task5_web_server/server.py
```
-> http://127.0.0.1:5005, там форма для оценок. Файла grades.json сначала нет, он создастся сам, когда сохранишь первую оценку.
