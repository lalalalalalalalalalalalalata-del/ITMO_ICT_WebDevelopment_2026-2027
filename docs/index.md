## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install mkdocs mkdocs-material
mkdocs serve
```

После запуска сайт будет доступен по адресу [http://127.0.0.1:8000](http://127.0.0.1:8000).
