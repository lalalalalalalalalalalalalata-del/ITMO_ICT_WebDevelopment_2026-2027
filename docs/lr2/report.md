Основные части проекта:

| Файл или папка | Назначение |
|----------------|------------|
| `manage.py` | запуск команд Django |
| `simple_django_web_project/settings.py` | настройки проекта |
| `simple_django_web_project/urls.py` | подключение URL-адресов проекта |
| `library/models.py` | модели тура, бронирования и отзыва |
| `library/forms.py` | формы регистрации, бронирования и отзыва |
| `library/views.py` | обработчики страниц |
| `library/urls.py` | маршруты приложения |
| `templates/` | HTML-шаблоны |

## Реализованные модели

В приложении `library` созданы модели `Tour`, `Reservation` и `Review`.

В модели `Tour` хранится информация о туре:

- `name` — название тура;
- `agency` — турагентство;
- `country` — страна;
- `description` — описание;
- `start_date` и `end_date` — период проведения;
- `payment_terms` — условия оплаты;
- `price` — стоимость.

В модели `Reservation` хранится бронирование пользователя. Пользователь может редактировать и удалять только свои бронирования. Администратор подтверждает бронирования через Django-admin или через отдельную страницу управления.

В модели `Review` хранится отзыв к туру: даты тура, текст комментария, рейтинг от 1 до 10 и информация о комментаторе.

## Реализованные страницы

| URL | Назначение |
|-----|------------|
| `/` | список туров, поиск, фильтр по стране и пагинация |
| `/register/` | регистрация нового пользователя |
| `/login/` | вход пользователя |
| `/tours/<id>/` | подробная информация о туре |
| `/tours/<id>/reserve/` | бронирование тура |
| `/tours/<id>/review/` | добавление отзыва |
| `/my-reservations/` | список бронирований пользователя |
| `/admin-reservations/` | управление бронированиями для администратора |
| `/reservations/<id>/edit/` | редактирование своего бронирования |
| `/reservations/<id>/delete/` | удаление своего бронирования |
| `/sold-by-country/` | таблица проданных туров по странам |
| `/admin/` | админ-панель для добавления туров и подтверждения бронирований |

В интерфейсе разделены права: обычный пользователь видит туры и свои бронирования, а администратор дополнительно видит страницу управления всеми бронированиями.

## База данных

Для локального запуска оставлен SQLite, чтобы проект можно было быстро проверить. Также добавлена настройка для PostgreSQL через переменные окружения:

```bash
export USE_POSTGRES=1
export POSTGRES_DB=tour_agency
export POSTGRES_USER=postgres
export POSTGRES_PASSWORD=postgres
export POSTGRES_HOST=localhost
export POSTGRES_PORT=5432
```

## Запуск

```bash

```
